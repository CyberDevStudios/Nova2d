# GitHub

The Nova2D source code and issue tracker are on GitHub.

## Repository

**New location**: [github.com/CyberDevStudios/Nova2d](https://github.com/CyberDevStudios/Nova2d)

The repository contains the complete framework:

- `src/` — framework source: states, entities, systems, and utilities
- `gestor/` — headless dependency manager with lockfile support
- `docs/` — documentation source, rendered live on this site
- `install.sh` — one-command installer for Linux, macOS, and Windows

## Releases

Stable releases and pre-release builds are published on the [GitHub Releases](https://github.com/CyberDevStudios/Nova2d/releases) page.

## Contributing

Contributions are welcome — every issue triaged and every pull request reviewed helps the whole community.

1. Fork the repository
2. Create a feature branch
3. Commit your changes
4. Open a pull request

## Reporting issues

Open an issue on GitHub with:

- What you were doing
- What happened
- What you expected to happen
- Love2D version and operating system

Include a minimal reproduction if you can — it makes the difference between a bug fixed in days and one fixed in months.
