# Community

Nova2D is built by developers, for developers. Whether you're shipping your first Love2D game or maintaining a production title, this is where you connect with the team and the community.

## Discord

The official gathering place for Nova2D developers — support, development updates, showcases, and direct feedback from the maintainers.

**What you'll find:**

- **Community support** — ask questions, share your Nova2D projects, get help, and learn from other devs
- **Development updates** — early access to new features, changelogs, and roadmap discussions
- **Showcase your games** — share what you're building with Nova2D
- **Collaborate** — find contributors, team up on projects, or just chat about game dev
- **Direct feedback** — talk directly with the maintainers and help shape Nova2D's future

The invite link is permanent — save it and share it with anyone interested in Nova2D.

## GitHub

The Nova2D source code and issue tracker live on GitHub.

**Repository:** [github.com/CyberDevStudios/Nova2d](https://github.com/CyberDevStudios/Nova2d)

The repository contains the complete framework:

- `src/` — framework source: states, entities, systems, and utilities
- `gestor/` — headless dependency manager with lockfile support
- `docs/` — documentation source, rendered live on this site
- `install.sh` — one-command installer for Linux, macOS, and Windows

**Releases** are published on the [GitHub Releases](https://github.com/CyberDevStudios/Nova2d/releases) page.

## Contributing

Contributions are welcome — every issue triaged and every pull request reviewed helps the whole community.

1. Fork the repository
2. Create a feature branch
3. Commit your changes
4. Open a pull request

## Reporting Issues

Open an issue on GitHub with:

- What you were doing
- What happened
- What you expected to happen
- Love2D version and operating system

Include a minimal reproduction if you can — it makes the difference between a bug fixed in days and one fixed in months.

## Proposing Features

Have an idea that would make Nova2D better? Open a [GitHub Issue](https://github.com/CyberDevStudios/Nova2d/issues) with the **feature request** template. Describe the problem you're trying to solve, your proposed solution, and any alternatives you considered.

The best feature requests come from real use cases — if you can share a concrete scenario where the current API falls short, that helps the maintainers understand the impact.
